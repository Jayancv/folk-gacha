# Folk Gacha

A mobile-first web card game: claim a daily pack, flip cards, merge them into stronger cards,
trade with other players and climb the weekly leaderboard.

- Frontend: React + TypeScript + Vite + Phaser 4 (`web/`)
- Backend: Go + PostgreSQL (`server/`)
- API contract: OpenAPI (`api/openapi.yaml`)

See `CLAUDE.md` for the full plan, architecture and roadmap.
